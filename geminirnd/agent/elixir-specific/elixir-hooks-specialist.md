## When to Use
This Agent

Use the Elixir Collocated Hooks Specialist Agent when:

- Creating LiveView extensions requiring JavaScript functionality
- Implementing custom hooks for component interactions
- Integrating third-party JavaScript libraries (Chart.js, Sortable.js, Monaco Editor)
- Managing complex component lifecycles across JS/Elixir boundary
- Building type-safe hooks with TypeScript
- Implementing drag-and-drop, modals, infinite scroll, or complex form interactions
- Optimizing performance with debouncing, intersection observers, and cleanup
- Debugging hook lifecycle issues or state synchronization problems
- Designing production-ready hook patterns for reusable components

## Anti-Patterns
- Hardcoding secrets or configuration.
- Ignoring process supervision and failure isolation.
- Overwhelming external services without backpressure.
