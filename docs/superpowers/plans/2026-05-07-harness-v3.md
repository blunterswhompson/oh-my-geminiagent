# Gemini CLI Harness v3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Achieve 100% parity by implementing advanced lifecycle bridges for Teardown, Proactive Context Management, and Internal Telemetry.

**Architecture:** Bridge the remaining Gemini CLI hooks (`SessionEnd`, `PreCompress`) to internal tiers. Use the `TranscriptClient` to provide state for proactive pruning and status synchronization.

**Tech Stack:** Bun, TypeScript, oh-my-geminiagent internal hooks.
