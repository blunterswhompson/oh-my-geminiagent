- [ ] **Step 1: Map `BeforeModel` to internal transform hooks**
Update `handleGeminiHook` to handle `BeforeModel`. Extract the `llm_request` (messages array), dispatch it to the internal `messages.transform` router, and return the modified request.
```typescript
case 'BeforeModel':
  const { eventHandler } = await getPluginInstance(directory, transcriptPath);
  const result = await eventHandler({
    event: {
      type: 'experimental.chat.messages.transform',
      properties: {
        messages: input.data.llm_request.messages,
        sessionID: input.data.sessionID
      }
    }
  });
  return { status: 'allow', llm_request: { ...input.data.llm_request, messages: result.messages } };
```
